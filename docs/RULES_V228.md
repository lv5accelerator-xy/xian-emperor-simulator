# v2.28 盟军有信：规则与兼容

普通局允许二至三镇共同结盟。例：“令袁绍与公孙瓒结盟，共讨刘表，合攻晋阳”。共讨对象是敌方，不会同时收到结盟邀请。每镇按实际对朝廷信任、守约信誉和本次执行度分别答复：信任至少30、信誉至少35、执行度至少45；进攻目标不得属于签约方或其现有友军。初始守约信誉50。任一拒绝则整份盟约未成立，不产生军令、协战或失信处罚。仅写共讨不等于正式结盟；否定条款不转为正面命令。

盟约从签署月到其后第四月（含首尾）有效。有效成员彼此非敌对，签约前的双方进攻令在各方同意后停止；第三方战争继续。相同有效条款不重复立约。A与B、B与C结盟不推定A与C结盟；不会自动替盟友的盟友宣战。未写共同城池目标的盟约只约定和平，不凭空决定出兵方向。

## 联军接令与实际协战

共同目标每月形成一项联军军议；前项仍有实际行军、交战或围城时不另开重复任务。首位签约方承担主攻，其余协战；防守任务各镇守备。每镇选择本方有建制军团，优先空闲者，独立核验军路、粮食、士气、疲劳、目标归属与既有任务。正在执行的军令、已接受援军约定优先，拒绝不会被写成接受。目标已由友方控制时不再发起共同进攻。

拟旨签约使用原有一次行动与外交成本。协调或劝止整项共同军议另用1行动；协调只为预计接受的主攻令收取每令1国库。各镇仍须符合皇权45、该镇信任60、人物关系50的朝廷调遣条件。交涉被拒仍消耗行动；拒绝协调不等于诸侯放弃月末自主决断，成功劝止只约束该镇本月军议。普通局每月仍只有2行动。付费请求按核心收据顺序恢复，后来的改令须匹配实际旧令。

军团分别沿本方实际路径行军，没有传送或远程加成。只有同一联军计划、仍有效的盟约、未溃散且已同城到场的军团参与城下战及围城；路战还须本月确实从同一起点进入同一条军路。每军独立耗粮、疲劳、伤亡。路战参战军团当月均不越过该路，也不再参加第二场路战。战报保留每军军令、到场兵力、伤亡与耗粮。

围城以实际到场总兵力及兵力加权士气、补给代入原公式；每城每月只计算一次城防与守粮损失。主攻不被盟军协战者替换。占领归实际主攻方，盟军不凭协战复制城池或国家收益。期限结束或背盟后，未完成的共同任务解除；已完成驻防保留，不能继续以旧盟约发动进攻。

## 背盟、守约与责任

签约后的实际敌对军令、野战、围城及占领会破坏相应盟约。朝廷明确撤换尚未抵达或仍在共同围城的军令，也属于撤离已接受的共同任务。必须有实际军令替换凭据；拟议、预览、签约前事实、接令前拒绝、战败、自动败退、断粮或期限自然结束不算主动背盟。

同一背盟方、同次根军令（撤换则为该次替换凭据）守约信誉至多扣13，影响以后邀请。朝廷背书另使实际受害方对朝廷信任至多扣5；相关签约方或背盟方的现有盟方可警惕，至多扣2。若同一诸侯已经对该攻势发出援军警讯，盟约警讯不再重复扣罚。诸侯自主背盟不扣受害方或观察方对朝廷信任；其自身守约信誉仍降低。普通军事的原有敌对信任−3、援约或停战的原结算仍分别保留，均展示实际封顶后的变化。

信任低于30、扩张意愿比谨慎高至少25的诸侯，可能在本月候选军议中提出对相邻盟方城池的进攻。仍须真实军团接令，接令时再次核验性格、信任、盟约、任务与军路；其他停战不被这一入口绕过。朝廷若协调该背盟军议，须在游戏中明确承担后果。

无背盟的完整观察期在最后一月军务结算完毕后才记守约。每方信任至多+4、守约信誉至多+3；同一方同一截止月只奖一次，防止重叠盟约刷取。共同军事目标是否完成另看实际军务，和平奖励不伪称攻城成功。

## 存档与历史

产品2.28.0、规则228、核心结构103；军议账本结构2，新增策略存储内盟约账本结构1，不增加独立存储键。旧成绩保留原规则。完整盟约、计划、各军回执、背盟根行动、实际处罚和观察奖励随全存档保存，界面仅截取近期显示。

旧“结盟”承诺若缺少正式同意凭据，进行中的记录标为历史待核，原有已结算结论保留。不从旧诏书、旧战报或缺失观察期补造盟友、出兵、信誉奖惩。载入时不会借历史显示窗口重新处罚。
