# v2.27 合议连衡：规则与兼容

普通历史局每月最多三镇提出军议，每镇选择一支仍有建制的军团，优先空闲军团。候选及优先序只由本局固定种子、月份和已有事实决定，查看、刷新与反复提交均不重抽。短局、每周挑战不增加自主军议。

## 并议与军令

朝廷仍每月只有两次行动。协调或劝止各用一次；协调被拒也消耗交涉行动。未处理军议在月末按记录的优先序、同序时按标识决定。已付费且尚未处理的舆图军令先恢复，已有执行令和已承接援约优先，后来的自主军议不能覆盖。

同军团另派任务先拒绝，保留旧令。地图复核须勾选“撤换正在执行的旧令”，并匹配打开复核时的旧令；旧复核页不能再次覆盖新令。自由诏令需明确写明“改令”“改派”等。实际替换后旧令记为已撤换；原援军若未抵达，沿原约核验失败，不伪造抵达。撤换本方围城会解除原包围。

选择地图“撤退”本身就是明确撤离，直接沿原撤退入口执行，不再要求另一项撤换勾选。

军议里的同城、对向和同军团提示只预警。实际请求或军团行动发生后才记冲突，不因提示扣城防、补给或信任。

## 实际军事顺序

1. 军团先按月初军路状况消耗粮秣，核验断粮、封锁、减员和路线衔接。未能出发者留在原城，不参与虚构的途中交战。
2. 真正出发、同路对向的敌对军团，至少一方执行进攻时发生军路遭遇。按军团与军令固定次序配对，一支军团每月最多参与一次路战。实际双方军令共同引用同一战斗事实。
3. 路战双方本月不跨越该路，胜方下月再行，败方停止旧令并就地整顿。照原战力、伤亡和粮耗计算，路战不损坏远端城防、不产生远端占领。其余实际出发部队正常前进，随后核验所在城池的野战与围城。
4. 同城敌对目标只记录争夺，实际野战与占领决定结果。本方多军协围时保持主攻军令，同一包围每月只推进一次。同月城下战败停止旧攻击令，有连通退路且仍有建制时另立撤退军令，并保留旧令和致败事实的联系。
5. 援军抵达立即登记原令的抵达月，随后才结算同月城下战斗。真实抵达且仍有建制者沿原约履约；后来的撤退不抹去抵达。覆灭仍按原援军规则失败。

## 外交连锁

普通停战只约束约定双方，不自动建立第三方同盟。第三方护援反应必须来自实际援约、已接受的具体军令，以及行动发生时尚在执行或驻守受援地的援军。受保护方与目的地在立约时冻结，不根据后来占领推测旧身份。

敌对军令、城下战斗、围城推进和占领，可以警示受援目的地的已承接援方；实际截击途中援军，也可警示其援方。见证在敌对行动发生时冻结，伤亡、败退、约定结算或历史展示裁剪不会抹去当时已经发生的观察。路战地点和原受援目的地分别保留。

朝廷背书的攻势，每个援方、受保护方和进攻军令最多扣一次信任2，记录实际扣值与触底时的零效果凭据；自主进攻只留警讯，不扣朝廷信任。原先军议对实际受害方的单次信任3、原约履行加7／失败减13继续分别核验、分别去重。不能把这些不同责任合成一笔未发生的惩罚。

同一实际战斗可同时关联援军失败、双方停战违约和援方反应。档案列出各自的实际结果与关联数量。近两月遭袭或护援警讯可令对应诸侯后续军议优先增防或护援，仍须重新检查军团、军路与已有军令，不自动撤换旧令，不把新军议追认为旧约履行。

## 存档

产品2.27.0，规则227，核心结构103。军议账本内部结构2，军团与战略旧存储键不变；持久保存军令、冲突、事实、约定和约定结果。军令界面最多展示50条，承诺界面前40条，军议卡片最近12条，完整存档保留其余历史。

已付费舆图请求只恢复一次，未付款暂存请求撤回，不凭暂存记录扣行动或出兵。旧版军令如有真实回执或军议快照则恢复已知记录；不补造未知历史。升级时已有军事事实列入新反应的观察排除清单，只保留旧结论，不追扣新的第三方信任。终局存档不补结过去约定；旧成绩保留其原规则号。

旧援约若缺少立约时的保护方，继续核验原履约，不根据当前城主推定新的第三方保护关系。
