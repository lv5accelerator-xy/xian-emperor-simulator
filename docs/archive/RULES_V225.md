# v2.25.0 规则、身份与迁移

产品版本 `2.25.0`，玩法规则身份 `225`，核心存档结构 `103`。本轮以 main `d6f2992` / v2.24.0 为基线；保留已有同步 commit、外围存储键、月结账本、完整恢复安装器与旧成绩。

## 规则与玩家行为

| 系统 | 当前规则 | 玩家实际取舍 |
|---|---|---|
| 停战 | 接令停止双方进攻，同时解除对应围城；月结重验任务。真实军令、野战、围城、占领按当时双方和月份核验。 | 发诏不保证外镇接受。主动重攻仍可选，预览和回执明确违约；第三方战争不冒充双方违约。 |
| 召见 | 国势/隐藏收益使用同月公共次数，关系按人物次数；首次100%、其后50%，向零取整。 | 轮换仍能结交不同对象，但不能恢复第二份完整国家收益。旧臣争权、掌权集团修好、外镇制衡各有代价。 |
| 当前人物 | 资格、代表、称谓共用 character-availability 查询；实际处理器拒绝不可用人物。 | 220 年使用曹丕和明确标识的机构角色；曹操旧个人关系、记忆、承诺不会无说明交给继任者。 |
| 延康主线 | 第3/6/9/11月四幕，第12月核验最终承诺；选择、效果、凭据同步保存。 | 交礼权关闭扣玺，遣散旧臣关闭最终联名；愿望、路线、纸面条款都不等于成果已兑现。 |

具体数值和条件集中在 [召见](../AUDIENCE_V225.md)、[人物](../CHARACTERS_V225.md)、[停战](../CEASEFIRE_V225.md)、[主线](../SCENARIO_220_STORY.md)。未把其他行动改成公共递减；其既有规则继续保留。

| story220 | 真实裁决、实际支出、来源后续、pending/fulfilled/broken/unknown、接入月与正常结束标记。无字段旧档从载入月接入，过去选择未知。 |

| 完整导入身份 | 读取传入信封内短局/结果身份；不沿用上一运行实例。短于12月或定向短局不插主线，普通220可从短局运行实例正确恢复。 |

## 同步边界与终月顺序

当前 commit 仍按世界、地方落实、军略/军团、外交事实、政议、因果、地方、阶段、方略与帝业同步收敛；本轮不恢复旧分支的定时器结算。主线裁决先在同一核心写效果、标记和凭据，再发真实决策事件。storyManaged 仅禁止通用系统重复安排同一延迟收益，人物记忆与历史仍留存。

终月先固定用度与随机风险，再世界/军略/军团、季度与其他后续，然后主线最后承诺、终值核验、原终局与后记。主线结果进入现有月结来源；终月中断续接不重发。现有 localStorage 故障模型与跨标签并发限制没有被扩展为数据库事务保证。
