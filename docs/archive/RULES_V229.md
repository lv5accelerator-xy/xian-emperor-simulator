# v2.29 外交终局：共奉有据

普通剧本的“诸侯共奉”、外镇方略的“天下共奉”和“帝国调停者”统一核验实际外交记录。国家数值与方略进度仍是必要条件，但不能代替履行与承接。其他结局及短局目标沿用原判定。

## 共奉条件

“诸侯共奉”保留制衡≥62、威望≥66；“天下共奉”保留外镇方略全部完成、制衡≥60、威望≥62。两者还须同时满足：

1. 至少一份各方明确同意、完整观察到最后军事阶段结束的正式盟约。拒绝、旧档未知或纸面承诺不算履行。
2. 至少两镇在结算月仍受有效条款约束，已实际观察至少两个月，对朝廷信任≥50、守约信誉≥40，且本镇无未修复背盟。期满当月已确认履行的盟约仍覆盖当月。
3. 当前可信支持者有共同战果，且相同成员有完整守约期；或同一组三镇形成至少两个不同期满月的守约期，并仍有可信在约支持。
4. 朝廷授意的背盟均已修复。

共同战果只认实际野战获胜或共同攻取城池，须两镇以上真实参战、各有正式军令、同属有效盟约及同一共同计划。建议、接令、到达、单独攻城、围城推进、城池当前归属均不能单独当作联军胜利。战败和自动退却本身不记背盟。旧版战报缺少胜方时不猜测；旧版占领事实可由同月同城同主攻令的真实围城贡献凭据佐证。

和平路线不要求发动战争。两个期满月必须有共同的三镇成员，不能把无关盟约或同月重复盟约拼成两期。

## 调停与未成结局

“帝国调停者”保留百官≥68、威望≥70、民心≥62，并要求完整盟约履行与至少两镇可信在约支持，或确实停止过双方进攻、全部承接、完成整个观察期的停战。原本无人进攻的停战文书不算实际止战。未修复的朝廷背盟阻断调停高结局。

国家数值达到共奉门槛而实证不足时，按实际承接可得“帝国调停者”，否则为“合纵未固”；有未修复朝廷背盟则为“盟约离心”。百官、民心达到调停门槛而无外交承接，记为“朝纲渐复”，不声称诸侯接受调停。

## 责任与修复

原盟约模型按根行动去重的真实背盟记录继续生效，不新增资源处罚。朝廷授意和诸侯自主分别计责；自主背盟影响本镇可信支持资格，不把责任转记朝廷。

重新签约不能消除旧责任。每一受害镇须与原背盟镇完成背盟发生后开始的至少两期守约，期满月不同；受害镇当前信任≥60，原背盟镇信誉≥40，才记为已修复。履约、背盟与修复总数均保留，修复不删历史。

## 保存与展示

策略存储内 `allianceDiplomacy.outcomeEvidence.version=1` 保存已确认盟约、实际战果、背盟及止战凭据，避免展示历史裁剪丢失既成事实。当前支持仍核对当前条款与信任，不靠旧凭据维持永久支持。

新普通局结束时，核心存档冻结 `diplomaticOutcome.version=1`，规则229。终局、千秋定论及两种帝纪导出共用该快照；刷新与恢复不重新评价。终评“制衡”分数受实际外交评分约束，新终评的“和”字拟谥另须有已满足的实际调停条件，不能只靠相对最高的制衡维度获得；旧版记录不重算。盟约面板提供只读预览和缺项说明，不消耗行动、资源或随机数。

核心存档结构103不变，不增加独立存储键。已有旧版终局保留原名称、文字与既有终评，不补判新功过。未结束旧档只使用能够核验的丰富凭据，缺少历史时保留未知。220年身份按当前势力解析，冻结后保留结算当时身份。

外交评分用于新终评的“制衡”上限：履约期数每期10分、可信支持每镇5分，合计至多35；可信共同战果30分，三镇两期和平路线25分；守信基础35分，每宗未修复朝廷背盟减20、自主背盟减5。未修复朝廷背盟另将总分限制为40；缺少当前局存储时不估分。国家数值的原制衡维度与此评分取较低者。该评分不改变普通剧本的国家收益或军力。
