# v2.30「和而有信」规则

战后议和和遣使修好位于军议与盟约面板。选择两个诸侯后可查看各镇答复及原因；预览不耗费行动、不改变随机状态。确认一次交涉消耗1行动、国库2，拒绝也计费，同月同事项不能重复付费。普通局仍为每月2行动，原始军力与经济不加成。

议和须有真实战事或背盟凭据，分别计算各镇对朝信任、扩张、谨慎、厌战及双方旧怨。战败比战胜积累更多厌战。双方同意后，实际军团停止针对签约对方的攻击并解除围城，保留位置、伤亡与旧令；第三方战事继续。和约需4个月真实军事观察才计完整履行；观察期结束后互不侵犯继续有效，直到真实违约。记录缺失记待核，不伪造完成，已确认的历史完成也不因记录截短被抹去。

背盟降低双边互信，形成受害方对背盟者的旧怨；与全局信誉、对朝信任分别保存。旧盟约不能靠同月重新签字洗白。议和实际观察至少2个月后可以遣使修好；使节承接、完整和平观察、互信与旧怨达到要求，才重新开放结盟。重新结盟不直接解除终局责任。

终局责任修复还须：受害双方在背盟后完成两期不同期限的守约（议和观察或正式盟约）、承接对应最新责任的修好使节、受害方对朝信任至少60、背盟者信誉至少40。修复保留原背盟记录。升级前已按旧规则完成两期正式盟约修复的事实继续承认，不追补奖励。

长期守约、议和和实际协战改善双边关系；高互信、低旧怨使诸侯更愿维持和平，受损记忆影响目标选择。对朝信任极低且扩张强、旧怨深的诸侯，议和至少2个月后可能自主毁约；自主责任与朝廷指令责任分开。同一道实际军令违反重叠盟约与和约，只产生一宗同源全局信誉处罚，分别保留条款及受害方。

外交终局在v2.29凭据门槛上增加已确认和约、修好与责任修复。当前可信和约可提供调停证据；未修复朝廷背盟仍阻止高阶共奉与调停。空白关系不能凭数值获得高外交结局。终局冻结关系与凭据，千秋定论、帝纪和完整存档共用。旧版已结束存档保留原结局、原文字和原快照。

产品2.30.0，规则230，核心结构103；双边关系账本结构1，嵌入现有战略存储，无新增存储键。付费交涉保存当时双方答复、原始军事边界与操作顺序；恢复按真实付费顺序处理交涉、舆图军令、军议干预和军令诏书，重复提交不重复扣费、停军或处罚。
