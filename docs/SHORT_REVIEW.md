# 短局复盘（v2.17）

复盘帮助玩家判断下一局的取舍。目标终值直接读取已核验成绩，不用某个行动的名称推断获章；三项显著处分按目标即时变化的绝对幅度筛选，并同时展示正负变化。后续回响、其他处分、月末用度与季度奖惩也影响终值，不能把入选处分当成唯一胜败原因。

| 数据 | 保存和核验时机 |
| --- | --- |
| 开局值 | 新短局开始、挑战修正施加完成后 |
| 裁决与行动 | 核心存档保存时读取真实回执；同一回执的即时政治回复更新原记录 |
| 月末净变化 | `xian:month-settled`，包含各系统和季度结算后的真实数值 |
| 目标终值与差额 | 已保存的短局成绩，发生提前终局时仍保留实际指标但不授章 |
| 下一局建议 | 针对未达目标；全部达标时选择余量较小的目标 |

复盘日志放在现有 `xian_emperor_short_challenges_v230` 活动局内，完整结果放在对应历史成绩内，不新增存储键。最多保存 40 条即时处分和 8 个月记录；结果仍只保留最近 40 局，界面展示最近六局。沿用 `rulesVersion: 216`，因为本版本只增加记录和展示，没有调整行动成本、目标、奖章或随机算法。

继续御览、完整导入后可恢复同一份日志。旧局没有日志时不推测原开局；续接月份显示“从续接时开始”。旧成绩保留已知终值，显示记录有限。结束后继续御览同步恢复复盘，不通过延迟插入生成重复或过时徽章。

“再试此短局”调用原短局开局流程，保留历史和纪念物；同题挑战调用已保存的定义，沿用其分享码和种子。普通固定短局没有同题随机种子，重试仍按普通规则开局，不承诺完全相同的随机结果。

## 验证

```bash
node tests/short-review-regression.js
node tests/settlement-replay-regression.js
node tests/decree-resume-regression.js
node tests/balance-regression.js
```

专项回归覆盖终月国库从 25 降至 24 的一分差额、季度奖励、回执含即时回复且不重复、滚动奏报后的选择保留、提前终局不授章、完成后刷新恢复、完整导入、旧存档、重试和纯复盘不消耗随机进度或资源。

手机检查：完成“许都夜变”，查看目标差额并展开逐月净变化；刷新后继续御览，确认同一复盘和奖章仍在。点击“再试此短局”应回到第 1 月，最近短局历史仍能展开。桌面浏览器结果不能代替真实手机验证。
