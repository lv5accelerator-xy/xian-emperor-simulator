# 《天子蒙尘：献帝模拟器》核心游戏设计文档

> 本文记录正式版的核心定位与基础循环；后续系统变化以根目录 `CHANGELOG.md` 和 `patch-notes/` 为准。

## 1. 产品定位

玩家扮演汉献帝刘协。游戏重点不是直接调兵占城，而是在军政资源匮乏的条件下，利用诏书、官爵、礼制、百官关系和地方诸侯之间的矛盾维持或恢复皇权。

核心体验：

> 法统最高，实权最低；每一次让步都可能换来生存，每一次自救都可能引发清洗。

## 2. 首发剧本

- 名称：建安元年·许都
- 开局：公元196年十月
- 长度：24回合
- 每回合：1个月
- 每月行动点：2

## 3. 每月循环

1. 收到一件中央奏报
2. 选择处置方案
3. 进行最多2次御前行动
4. 结束本月
5. 结算国库、民间稳定、曹氏警戒与泄密风险
6. 进入下一个月

## 4. 六项公开指标

| 指标 | 作用 | 危险状态 |
|---|---|---|
| 皇权 | 决定诏书执行率和制度影响 | 过低时政令层层拖延 |
| 汉室威望 | 代表天下对朝廷正统性的承认 | 归零触发“天下弃汉” |
| 宫廷安全 | 代表皇帝、后宫与近臣安全 | 归零触发“深宫幽闭” |
| 国库 | 支撑赈济、赏赐、仪典和秘密行动 | 枯竭会拖累百官与威望 |
| 百官支持 | 决定行政执行和政治响应 | 过低时尚书台难以运行 |
| 曹氏警戒 | 代表曹操集团对皇权的戒备 | 达100触发封锁或密谋败露 |

## 5. 五项隐藏指标

- 忠汉网络：愿在关键时刻支持皇帝的人员与关系
- 泄密风险：密诏、私会和使者往来被发现的概率
- 外部制衡：河北、荆州、江东等外镇对许都权力的牵制
- 民间稳定：粮价、赋役、流民和地方治安的综合状态
- 南方退路：朝廷在许都失控时转移至荆州等地的可行性

玩家只能看到定性描述，不直接看到精确数字。

## 6. 可用行动

### 拟写圣旨

玩家自由输入命令。本地规则识别：

- 赈济
- 减赋
- 察吏
- 整军
- 礼制
- 密令
- 任官
- 外交
- 安抚

执行率由皇权、百官支持、曹氏警戒和泄密风险综合决定。

### 召见人物

公开召见强化制度与百官支持；私下召见更能提升关系，但会增加警戒或泄密风险。

### 任免封赏

用官爵换取支持，能强化皇权和人物关系，但过度使用会刺激曹氏并削弱官爵价值。

### 密令联络

建立忠汉网络、情报线或退路。收益高，风险也最高。

### 赈济减赋

消耗国库提高威望和民间稳定。实际执行率取决于行政能力。

### 整饬朝仪

通过大朝会、宗庙祭告或经筵恢复朝廷存在感。

### 安抚曹氏

降低曹氏警戒并换取安全，但通常要牺牲部分皇权或财政。

### 结交外镇

通过诏书、密使和官爵建立外部制衡。

## 7. 人物模型

v0.1使用单一关系值与固定影响力。后续版本计划拆分为：

```text
对汉室忠诚
对天子个人好感
对曹氏恐惧
个人野心
家族利益
政治影响力
当前压力
```

同一人物可以公开支持曹操，同时私下愿意维护汉室礼制。

## 8. 事件结构

事件分为：

- 朝政与制度
- 宫禁与密谋
- 民政与粮赋
- 外交与诸侯
- 军事与战报
- 礼制与宗室
- 人物关系

固定事件负责形成剧本节奏；随机事件提高重复游玩价值。

## 9. 终局逻辑

终局不是单纯“复兴汉室/失败”二分，而是根据公开和隐藏指标共同判断：

- 再振汉纲
- 诸侯共奉
- 衣冠南渡
- 帝国调停者
- 许都守成
- 有名无实
- 风雨续祚
- 深宫幽闭
- 天下弃汉
- 密谋败露
- 朝廷解体

## 10. 数值设计原则

- 所有公开与隐藏指标范围为0—100
- 强力行动必须同时带来资源消耗或政治风险
- 皇权越高，曹氏警戒通常越容易增长
- 密令越多，泄密概率越高
- 国库、百官和民间稳定形成长期连锁
- 不允许AI直接决定或修改核心数值

## 11. 正式版进度层

- 单局先选一条御前方略，三个阶段只引用现有国势、隐藏局势、圣旨和行动记录
- “本月要务”每月只突出三件事，避免让玩家同时处理所有扩展系统
- 简明界面默认隐藏天下、军略、军团和政议摘要，完整界面保留全部深度
- 五名核心人物各有三章连续事件；人物事件不占奏报，不消耗行动点
- 方略、人物遗物、称号、外观和终局进入跨局史册，但不提供无限倍率

## 12. v1.0存档原则

- 核心单局存档带有 `schemaVersion: 100`，旧存档读取时自动迁移
- 御前方略局内状态与跨局收藏存于 `xian_emperor_progression_v100`
- 导出使用完整存档信封，覆盖全部独立本地存储；导入仍兼容旧版核心 JSON
- 不因升级重置玩家的剧本史册、军团、政议、音频或其他扩展系统

## 13. v2.1—v2.5减负与重复游玩原则

- 默认使用“简明御前”，一个月先突出裁决、可选行动和结算三步；完整系统仍可随时展开
- 重要决定只形成小幅、有限次数的延迟回响与承诺检查，不增加新的养成货币
- 乱世短局固定事件顺序并限制为四至六个月，奖励仅为勋章和纪念史签
- 天下同题通过确定性分享码复现相同局势，第一阶段完全本地运行
- 终局评价同时记录功绩、代价、人物关系与未兑现承诺，失败结局也保留过程意义
- v2.5之后暂停横向扩充系统，下一阶段优先优化九州大地图的信息层级与军令交互
