# v2.25 召见的公共收益与人物交往

召见仍消耗一次行动。国家收益按本月全部成功召见计次，人物交往按对象单独计次；换人或换公开／私下方式不能恢复国家收益。首次系数为 100%，第二次起为 50%，有利变化向零取整。国家系数作用于国势和隐藏指标，人物系数只作用于人物关系，同一收益不会连续乘两次系数。

`src/action-plans.js` 的 `AUDIENCE_ROLES` 集中配置政治角色，执行、预览、比较与推荐都使用 `XianActionPlans.build`：

| 角色 | 公开召见的基础国家变化 | 私下召见的基础国家变化 | 用途与代价 |
|---|---|---|---|
| 汉室旧臣 | 皇权 +3、百官 +3、警戒 +2 | 皇权 +1、安全 −1、警戒 +3；忠汉网络 +4、泄密 +3 | 建立公开支持或密线，须承担掌权者的戒备。 |
| 掌权集团 | 安全 +3、警戒 −5、皇权 −1、百官 +1 | 安全 +2、警戒 −4、皇权 −1；泄密 +2 | 用政治让步争取安全，不能同时免费提高皇权。 |
| 外镇 | 威望 +3、国库 −1、警戒 +3；外部制衡 +3 | 威望 +1、国库 −2、安全 −1、警戒 +4；制衡 +5、泄密 +3 | 争取名分和后续合作基础，召见本身不是援军已到或外交承诺已兑现。 |
| 内廷 | 百官 +2、安全 +2、警戒 +1 | 安全 +2、警戒 +2；忠汉网络 +2、泄密 +2 | 维持宫禁和联系，仍承担政治、泄密代价。 |

公开关系基础 +4，私下关系基础 +7。费用、行动点和不利影响不递减；主议的费用折让及其他修正先加入计划，再对相应有利变化使用一次系数。上限后的实际变化进入预览与回执。国库不足会拒绝主动行动，不消费两种计数或主议额度。

例如同月两次公开召见杨彪，合计皇权 +4、百官 +4、警戒 +4、杨彪关系 +6；改成杨彪、董承各一次，国家变化相同，人物关系各 +4。轮换有结交价值，但不会再获得完整第二份国家收益。上例以未触及数值上限、无主议的 196 年有效人物为前提。

## 保存与兼容

核心 `actionRepetitions: {turn, counts}` 同时保存 `audience:state` 与 `audience:<对象ID>`，新月一起清空。计划的 `repetition.keys` 由成功执行统一登记；预览、取消、拒绝、保存和重复读取均不递增。

旧档存在当月明确的各人物召见计数、但没有公共键时，以这些计数之和作为公共次数；首次新规则成功行动将其写为公共键。完全没有计次历史时从零开始，不根据关系值或史官文本补造旧行动。其他行动仍使用各自原有的 `actionId:targetId` 规则。该玩法调整使用新规则身份，旧成绩不重算，直接同题比较仍须规则身份一致。

当前人物由 `XianCharacterAvailability` 查询。曹氏旧势力键可保留，但召见、关系和行动对象使用当时实际人物或明确标识的机构角色；曹丕不接收曹操的个人关系。

## 可复现验证

```powershell
node tests/audience-common-regression.js
node tests/decision-depth-regression.js
node tests/action-plans-regression.js
node tests/balance-regression.js --json
node scripts/audience-balance.cjs
```

`audience-common-regression` 覆盖轮换、同人及换方式、政治角色、费用与拒绝、真实主议与额度、预览纯度、推荐／比较、完整导入、旧次数及新月。`decision-depth` 保留原有主议、比较与存档边界，更新“换人物恢复完整国家收益”的旧断言。

`balance-regression` 复用每格 24 个固定种子 `Math.imul(i,2654435761) >>> 0`，加入同阵营轮换策略，五短局 × 四种政策与一个按目标补缺对照，共 600 局。旧的 `revenue-method: "austerity"` 已改为 `"audit"`。每次策略调用检查真实行动次数是否增加，拒绝时带原因失败，不能将未执行的行动计为成功；JSON 保留逐局目标失败、提前终局、费用、行动记录和种子。

`audience-balance` 是受控的两行动边际比较，不是完整战役胜率：钱粮紧张、高警戒、追求皇权三种明确初始局面，比较同人、同阵营轮换、修好掌权集团、召见后筹措／朝仪／密联／外镇七种序列。每组分别不选主议、实际选择伏皇后、上月真实消费两次主议额度，记录采纳即时效果及额度；随后统一预置国势以隔离本月行动的边际效果。预算固定两行动，国库不足的原定行动保留为失败，不偷偷改用成功策略。局面权重和政策在脚本中公开，不能将其解释为对所有玩家都最优。

最终取样数量、实际结果、失败样本和源码身份随本轮验证报告记录；本页不以脚本存在代替已执行证据。
