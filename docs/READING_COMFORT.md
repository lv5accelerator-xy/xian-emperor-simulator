# 御览从容：字号与月报

v2.23.0 增加标准、大字、特大三档字号，独立于古风／清晰字风。开局和结局可直接选择，桌面游戏的“更多”与手机状态条上方可依次切换。

`src/reading-settings.js` 在 head 中恢复 `xian_reading_size_v1`；标准使用原字号，大字和特大增大根字号及关键正文。设置不写游戏存档，不消耗行动、国库或随机进度。存储受限时当前页仍可切换，刷新后可能恢复标准。其他标签页的字号修改会同步，字风与字号互不覆盖。

月报默认先看实际短局目标、按变化幅度选出的最多三项公开指标净变与已记录的月末警讯。目标读取该月结算保存的实际值，满足当前目标不等于终局获得奖章。净变采用月初快照至结算后的结果；快照不完整时明确显示载入后的变化。警讯来自本次月末新生成的 danger／warning 记录，以及月末结算明确记载的俸粮不足、民间不稳；旧月报没有单独记录时不补造。

处分与执行评估、完整国势、结算对账与庶务、总评与提示默认折叠，原始数据完整保留；非圣旨执行估计继续标明为估计。查看和折叠不重新结算、取随机数或保存游戏。月报样式移至独立 CSS，统一采用本地字风与可调字号。

手机的简明／完整模式都显示“裁决／行动／月末”，当前步骤及已完成状态使用可访问名称说明。月报正文单独滚动，底部继续按钮和顶部关闭按钮保持可操作；支持 Escape、Tab 循环与关闭后的焦点恢复，并考虑动态视口和安全区域。

```sh
node tests/reading-settings-regression.js
node tests/monthly-summary-regression.js
node tests/typography-regression.js
node tests/settlement-audit-regression.js
EXPECTED_VERSION=2.23.0 node tests/release-regression.js
```

网页验收使用 `tests/narrow-screen.html` 的 390 像素框，组合核对三档字号与两种字风；刷新后继续同一存档，日期、行动、资源不变。核对月报摘要和完整对账，展开明细后底部按钮不应被推走；取消预检和反复查看月报不产生额外结算。

真实 iPhone 最小验证：Safari 打开公开游戏，选特大字号并刷新，确认选择保留；继续一局，完成裁决、月末预检和月报，展开明细后点击继续。文字应完整、页面不横向溢出、按钮可触达并进入正确的下一月。桌面窄屏与 CI 不代表真实 Safari 触屏验证。
