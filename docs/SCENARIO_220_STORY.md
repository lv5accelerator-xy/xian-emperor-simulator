# 汉祚将尽：延康十二月主线

v2.24.0 将普通「延康元年·禅代前夜」串联为四幕历史主线，保留第 1 月「禅代试表」和 12 月全局终值判定。主线以曹丕的魏王府、尚书台、杨彪与宗室为叙事主体；杨彪的既有关系值用作旧臣信任。没有增添资源货币、框架或存储键。既有通用人物、随机事件与系统仍属于游戏化近似，本次不重写其历史人物池。

## 调度与真实分支

调度优先级为：短局／同题定向事件 → 剧本开场 → 196 年固定事件 → 普通 220 年主线 → 帝业事件 → 因果事件 → 原随机池。其他四个剧本的池与固定事件不改。同题继续使用原分享码、mulberry32-v1 随机流、规则版本与评分公式。

| 回合 | 章节 | 前因与取舍 |
| --- | --- | --- |
| 3 | 百官联署 | 封止联署增加皇权并伤安全；许议名分换缓期但损权威；私护旧臣支付钱粮并增加泄密风险。 |
| 6 | 宗庙与旧臣 | 核验第 3 月的真实后续；杨彪、百官、忠汉网络决定是否愿争任命权。可交传玺礼权换保护名册，或遣散旧臣护家属而失去公开争权力量。 |
| 9 | 玺绶之争 | 先前交出的礼权关闭扣玺路线。有效保护名册或充足官心与杨彪信任才可立约；行在使者须已有退路与钱粮；交玺保宫始终可作代价明确的退让。 |
| 11 | 最后朝议 | 留玺回声、未散旧臣、皇权 ≥38、官心 ≥45、安全 ≥36、忠汉网络 ≥24、杨彪 ≥65、警戒 <82、泄密 <45 才能联名拒禅；旧约和政治资本允许议事谈判；真实通路与接应才可分护宗室。保全选择牺牲皇权，不能保证全部免追。 |

每项政治方案仍需支付标示的钱粮。第 6 月疏散与第 11 月保全在钱粮不足时改为缩减安置：不凭空扣出负国库，安全收益降低、百官另受损，以保持裁决可继续。第 3 月许议和第 9 月交玺无需钱粮，但牺牲权威或名分。未知结果明示待核验，不在提示中保证成功。

四幕进入本身不算完成。若加载发生在某节点已入奏但未裁决时，原奏报和选择保留。若不完整新档错过节点，调度取已到期、尚未解决的最早节点，按实际当前回合记录；不挤掉定向挑战。缺少新状态的旧档以载入回合作为接入点，只进入其后的章节，早先选择保持未知。

## 保存、后续与终局

`src/scenario-220-story.js` 提供纯规则与安全呈现；`src/game.js` 负责真正应用效果、去重、日志与统一保存。核心 `story220` 包含：

| 字段 | 内容 |
| --- | --- |
| version / entryTurn / phase | 规则结构版本、真实接入回合、已裁幕数（归一化时由裁决重新计算） |
| decisions | 以唯一事件 ID 为键，保存选择键、实际回合、已裁标记与直接实际公开／隐藏变化；不保存可注入的选项 HTML |
| consequences | 唯一后续 ID、来源裁决、固定核验回合、pending / fulfilled / broken、兑现回合和实际效果 |
| promises / stance | 已记录选择对应的承诺状态与最后政治立场，归一化时从有效裁决与后续推导 |
| completedNormally | 只有原核心完成正常剧本判定时设为 true；提前失败不据此追加主线成功叙事 |

第 6、9、11 月入奏前核验对应后续：例如私护旧臣在密线安全时带来杨彪回牍与有限官心支持；交礼权在国势允许时登记保护名册；立约在后月获得或失去确认。第 12 月的最后承诺在核心用度、天下、军路、军团与季度结算后核验，进入既有月末来源账本；效果与完成标记保存后，即使终值核验中断也不会再发放。

主线决定继续传给人物记忆与因果历史；其延迟后果由主线独立管理，通用旧事／因果延迟器不另造重复承诺。一次决定的实际效果、记录与裁决标记在外部监听器可能保存之前写入同一核心。完整存档、备份、刷新与导入沿用现有信封；导入短局读取信封里的短局身份，避免从旧运行实例误加主线状态。

缺损、不合法的选择／后续会被丢弃；不从 `phase`、按钮标签、纪事字符串或人物印象反推出选择。未知主线事件 ID 回到原有效奏报，避免不可继续。过去的选择未知时，未来章节与后记明确保留未知。

专属后记只在普通 220 年正常完成 12 月后追加到终页、帝纪终评和文本实录，区分抗争、宗庙旧臣保全、妥协／谈判的有限空间。它引用实际选择、直接代价、杨彪关系、百官终值、承诺核验和既有终局；既有方略终局、国势评估优先，提前失败和短局不追加。旧完成档无故事记录时，仅列可证实的终局与国势。所有新增 HTML 对导入文本转义。
