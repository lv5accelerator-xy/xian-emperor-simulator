# 可访问性快检

修复续记：v2.30.2已针对A11Y-01/02实现[通用弹窗焦点修复](MODAL_FOCUS.md)，并补充Node回归及桌面/手机原生键盘检查。v2.33.0处理了A11Y-03，v2.34.0处理了A11Y-04并补做舆图键盘操作，v2.36.0补齐其余窗口的键盘操作（见下三节）。以下表格保留原审计时的现象。

## v2.36.0 各窗口的键盘操作

逐一用键盘打开舆图、御前档案、军团、说明、存档备份、月末预检与月报（1366 宽，舆图另测 390 宽）。通用弹窗与月报原已合格；自建窗口有三类问题，均已修复：

- **焦点不进窗口、Tab 走到背景**：舆图、御前档案、军团等窗口打开后焦点仍留在背景的按钮上，Tab 在页面背后游走，Esc 关闭后焦点落到别的按钮或页面顶部。现在 `src/modal-focus.js` 自动接管所有 `role="dialog" aria-modal="true"` 的窗口：打开时焦点移入、背景设为 inert、Tab 不出窗，关闭后焦点回到打开它的按钮。窗口可以层叠（如舆图上再开通用弹窗），只有最上层窗口的背景是 inert。
- **一次 Esc 关掉两层**：通用弹窗叠在舆图上时，Esc 同时关掉弹窗和舆图。现在通用弹窗关闭后不再把这次 Esc 传下去，各窗口在被上层盖住时也不响应 Esc。
- **焦点随内容消失**：舆图指引“跳过／下一步”、州郡详情与“返回全国舆图”整块替换内容时焦点掉回页面顶部，现在分别移到地图、下一步按钮、返回按钮或当前标签页。舆图 SVG 原整体标为 `aria-hidden`，里面可聚焦的州域、策略区域与军路读屏看不到；现在只把底图、水系、地名等装饰层标为隐藏。
- 把关：`scripts/browser-keyboard-screens.cjs`，已加入 CI。导入按钮打开的是系统文件选择框，不在检查范围；首页“展开军团”等摘要按钮在当前版式中不显示，未检查。

## v2.34.0 舆图键盘操作与按钮名称（A11Y-04）

- **舆图键盘操作**：原先军情栏整块替换后，刚按下的按钮随之消失，焦点掉回页面顶部，键盘用户要从头再按 Tab；下令时只能在地图上逐个 Tab 到目标城池。现在：
  - 打开军团、开始下令、路线复核与下令成功后，焦点移到军情栏的新标题，下一次 Tab 即到可用按钮；从地图点选城池、军路时焦点留在原处，内容由读屏播报（`aria-live`）。
  - 下令时军情栏提供目标城池下拉列表与“预览路线”按钮，可用方向键选择；Esc 取消军令。
  - 城池、军团标记、州域与策略区域有明显的焦点环。
  - 修了一处鼠标也会遇到的问题：桌面端下令成功会同步重绘整幅舆图，回执一闪即逝，新舆图还残留“正在下令”的样式。
- **A11Y-04**：军议、联军两张摘要卡的按钮名称只取标题（如“本月并行军议 · 3 镇 · 3 项待决”“诸侯结盟与联军 拟旨邀请二至三镇结盟”），军议清单、说明与示例圣旨改为按钮描述，读屏仍可读到。
- 把关：`scripts/browser-map-keyboard.cjs`（只用键盘在 1366 与 390 宽度各下一次军令，已加入 CI）、`tests/brief-names-regression.js`。仍未用 NVDA、VoiceOver 等真实读屏软件试听。

## v2.33.0 对比度复核（A11Y-03）

自动工具（axe-core）无法判断渐变、插图和半透明叠层上的背景，大部分文字被记为“需人工复核”。因此改为按实际渲染测量：每个屏幕截两张图，一张正常显示，一张把文字设为透明只剩背景；前景取计算样式色（乘上祖先透明度），背景取该文字区域内像素的中位亮度，按WCAG 2.2最低对比度判定（普通文字4.5:1，大字3:1）。

- 范围：开局、第一月顶部与中部、月末预检、月报、山河舆图，各在1366×900与390×844两种宽度，共12个屏幕、510个文字元素。SVG地图标注自带描边，另由人工查看；禁用控件不计。
- 修复前46个元素、14组样式低于阈值，主要是统计卡小字、页脚、行动分类说明、军团与策略网络摘要、舆图图例与信息栏、非重点城池名。
- 修复：调亮这些文字色；舆图城池的“防/粮”小字加深色底；聚焦模式下非重点城池只淡化图标，不再淡化名称。修复后0个低于阈值。
- 把关：`scripts/browser-contrast.cjs`，已加入CI浏览器回归。它只覆盖上述屏幕，不是全站或全状态认证。

本轮只记录问题，未修改样式、Tab顺序或弹窗行为。检查环境为本机Chrome、file://直接打开、1366×900和390×900；覆盖开局、普通局第一月、桌面御前手册弹窗。使用真实指针点击、原生Tab/Escape和浏览器Accessibility Tree，并人工查看两种宽度截图。结构化结果见[检查摘要](data/a11y-summary.json)，完整DOM记录及截图随交付证据保存。

A11Y-01/02为实际键盘复现；A11Y-03是源码色值结合截图底色的近似候选，不是全站对比度认证。初次按透明层叠粗算出的白底候选未作为失败统计，因为页面使用多层渐变，不能将白底近似当作实际背景。禁用按钮灰化没有计为对比度缺陷。

参考[W3C模态对话框模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)的焦点循环与关闭返回要求，以及[WCAG对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)的普通文本4.5:1、较大文本3:1口径。来源仅用于解释检查方法，不据此宣称通过无障碍认证。
