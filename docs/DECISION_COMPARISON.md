# 择策、转折与两局对比（v2.20）

## 行动比较

裁决奏报后，推荐卡片先显示主要收益和代价，详细依据单独折叠。“比较方案”在原处分弹窗展示当前建议、最多两个具有不同数值取舍的候选，以及留行动守成的基准。相同数值结果归为一个候选；实际人物仍可在原行动窗口修改。

候选来自八类常用行动的共享规则，要求当前可负担并留出至少一份月末用度。以限幅后的公开、隐藏指标及人物关系净变化筛选不同取舍，过滤已知数值上全面更差的候选；不预知人物后续故事。表格列出当前、行动后、固定月末后、相对守成的差额，以及目标与泄密风险。固定预估不包括未抽取的随机风险、即时回应与其他系统回响。

打开、展开、返回与预选不花资源，也不写入随机进度。选定方案进入原行动窗口，确认后才执行；守成先打开原月末预检。比较窗口保存当时局势签名，背景变化后选定时重新生成，不能套用旧窗口的数值。实际行动仍重新检查当前预算。

## 目标转折

在已有短局复盘日志中追加已封卷的真实月末来源，不新建存储键。短局终月或提前覆灭时，核心先封卷再记录成绩，所以最后一月来源也进入复盘。最多保留八个月结算来源。

每项目标优先解释首次记录的跌出；没有跌出时选择首个未达的已记录月末，或余量最小的一月。月内处分与月末来源按已记录顺序判断，终局达标情况独立显示；季度奖励恢复目标时保留先跌出、后恢复的过程。

当月分解满足：`月初 + 裁决净变化 + 行动净变化 + 其他月内变化 + 所有月末来源 = 月末实际值`。没有逐项归类的月内变化明确标为未逐项记录，中止或续接的月份标为有限记录。旧复盘缺少来源时不回填，不把某一个转折当作最终胜败的唯一原因。

## 同题两局对比

从 v2.20 新开的同题开始，在现有活动局及结果内保存比较身份：合法分享码、真实随机种子（含零）、规则版本、随机算法、剧本、难度、期限、事件顺序、目标和开局修正，以及修正后的公开指标、隐藏指标、人物关系和初始随机进度。身份不包含开局时间。继续沿用 `rulesVersion: 216`，因为本版本没有改变数值、成绩或随机算法。

终局及最近短局历史选择时间顺序上最近的一局匹配记录，而不是分数最高的一局。只配对一致的身份；普通未设种子的固定短局、不同条件、旧成绩和缺少开局身份的局不直接配对。

对比展示两局实际成绩、目标终值及差额、御前行动次数、处分国库净支出及每月不同的已记录选择。支出是处分回执中实际国库净减少之和，包含同步反馈，不含月末用度；不是行动预算总额。缺少完整投入记录时显示“未记录”，不记为零。两局起点相同，操作差异仍会改变随机进度的消耗和后续回响，比较不承诺某个选择必胜。

记录随原完整存档导入、导出及备份恢复。新结果保留最近四十局，历史界面仍展示最近六局，不改变现有最佳成绩与收藏。

## 分数解释与紧凑结局（v2.21）

本次核验时保存真实输入，继续使用 `round(达标项数 / max(1, 总项数) × 1000 + 威望 × 2 + 皇权)`。显示两位小数的计分项与取整调整相加等于总分。提前终局不授章、不计分，各项按零计。目标终值的余量不单独加分。

同题对比把总分差拆成目标、威望、皇权及取整差。例如同为三项目标达标，威望 91 → 84、皇权 53 → 35，目标分不变，威望分 −14、皇权分 −18，总分 1235 → 1203。这是评分输入的算术解释，不能把单个选择当作全部差异的唯一原因。

旧成绩没有评分时输入时只保留原分和总分差，不从总分反推两项国势。导入构成与原分、达标项数或规则不一致时也显示未知。新输入保存在原短局结果中，刷新、完整导入与备份按原路径保留；不新增存储键、不改变比较身份。

比较卡片把固定月末后的每项目标数值、余量或差额，以及未抽取的泄密概率与触发损失放在折叠表格之前；守成不会消除尚未检验的风险。短局结局先显示勋章、总分、一项关键记录和第一条下一局建议，摘要后可立即重试；其他转折、国势与评分细节按需展开。提前终局摘要说明真实结局，不把某项目标转折编造成终局原因。

```bash
node tests/action-comparison-regression.js
node tests/review-turning-points-regression.js
node tests/same-challenge-regression.js
node tests/score-explanation-regression.js
```

专项回归执行真实比较入口、原菜单预选与确认、局势变化重算和守成预检；检查实际月末用度跌出目标、季度恢复、完整短局分解、重新载入与旧记录。两局对比通过实际同题游玩，核对身份门槛、终值、投入、选择、完整导入和未知数据，并检查导入文字转义。

`tests/narrow-screen.html` 以单个 390 × 844 像素 iframe 加载真实游戏，检查比较卡片、折叠表格和原确认按钮；与主页面共用存档，不模拟手机浏览器。

桌面网页检查不代替真实 iPhone。Safari 最小检查：打开比较并取消，确认资源未变；选一个候选，再在原窗口确认；结算后展开转折来源；完成相同同题两次查看对比。另在“存档备份”导出一份完整备份，确认文件可下载，导入并重新加载后继续御览，月份和待办步骤应一致。
