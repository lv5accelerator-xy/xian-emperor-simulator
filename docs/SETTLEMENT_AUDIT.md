# 结算对账、具体推荐与备份差异（v2.19）

## 玩家流程

裁决奏报后点击推荐，会打开原有行动窗口并预选具体方案与人物。说明列出全部短局目标中受影响的项目及主要代价；玩家可以修改选项，确认后才消耗行动。目标有余量或没有更稳妥的可行改善时，可留行动守成。

推荐比较当前可见的行动规则、0–100 上限、余下行动守成、月末用度和失败风险。它不抽取未来随机数，也不预知后续奏报、人物反馈、军团变化或季度结算；预估达标仍可能在实际结算后改变。

月末预检取消不产生对账记录。确认后，实际结算完成事件生成月报并归档，月报新增“预检与实际结算对账”。逐项显示结算前、固定预检、实际终值及差额，列出真实记录的变化来源；短局目标同时核对实际达标情况。终局页的“结算对账”可复查最后一个月。

## 实际数据

`monthly-safety.js` 提供纯预检与对账构造函数。核心在月末各阶段记录 `applyPackage` 对公开及隐藏数值的真实变化，包含固定用度、泄密检验、旧事回响、天下、州郡军路、军团和季度奖惩。固定与泄密仍合并施加后再限幅，保留原结算规则；归因按固定预估加实际增量分解，上限造成的额外差异纳入实际增量。

每一项“实际 − 结算前”等于列出的来源净变化之和。无法归类的残差标为“其他变化（未归类）”；没有记录的旧存档不补造来源。核心 `pendingSettlement` 保留中断的月末过程，`lastSettlement` 保存最近一次完整结果，月报档案保留对应历史。已有固定结算但缺少过程的旧存档续接标为部分记录，不重复扣款。

`action-plans.js` 是八类常用行动的共享规则，提供具体方案、人物、投入及变化。实际执行重新核对当前钱粮，所有耗资常用行动都拒绝余额不足的方案。外镇人物加授官职的额外威望在缺省项上从零计算，避免出现非有限数值。短局目标和成绩仍沿用 v2.16 规则。

## 备份

继续使用 v2.18 的备份索引，保留最近三个完整月度留档及一份替换前留档。列表补充挑战或剧本名称、备份时间和存档版本；恢复确认展示现局与备份的月份、行动、公开指标、泄密、忠汉网络及固定随机进度。跨局恢复另行提示。恢复仍先归档现局、写入全部系统并重新加载。

“导出此完整备份”下载选中的留档，而不是当前自动存档。打开对比、取消及下载均不推进月份、不花资源、不推进随机序列；备份索引不嵌入自身快照。

## 验证与局限

```bash
node tests/action-plans-regression.js
node tests/settlement-audit-regression.js
node tests/backup-compare-regression.js
node tests/advice-playthrough-regression.js
```

84 种实际行动组合核对预选字段与确认后的真实数值。对账覆盖预检取消、真实月末归档、季度终月奖励、限幅、泄密、未知残差及读档；备份覆盖名称、版本、差异、取消和选中留档的完整下载。

推荐实跑使用每类短局 24 个固定种子，分别采用首项、次项或可见目标收益引导的奏报选择；两组使用相同奏报选择方法。一组按正式推荐执行常用行动并确认预检，一组保留全部行动守成。全过程不修改资源或目标，不提前抽取随机数。下表是测试策略结果，不代表真人胜率或任意事件选择的保证。
