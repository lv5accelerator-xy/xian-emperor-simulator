# v2.26 固定种子玩法对照

基线2.25.0（main 572a47e）与本轮2.26.0，五个普通剧本、共同种子226001／2654435761／42424242。基线15局；新版不干预、协调、劝止各15局，共60条完整轨迹，全部到达各自真实期限（12／18／24月）。军务与资源逻辑的五份源码在采样前后哈希一致，五个剧本使用同一组源码；每条轨迹保留实际选择、费用、拒绝原因、军议、军事事实、外交责任和结束状态。

所有策略均使用可见状态选择奏报、最多每月两次真实行动，不修改国库、皇权、军团或外交指标。干预策略优先尝试本月军议，再将剩余行动用于同一公共建议器；不干预与基线把行动用于公共建议器。预览提示会拒令时，干预策略仍尝试一次，以保留交涉失败的真实机会成本；这不是建议玩家无条件干预。有效停战风险不由采样器自动勾选。

“回执”按行为计数：一次朝廷交涉被拒后，主将仍可能自主接受或拒绝，所以拒绝数可能超过军议数；并非同一处罚或军令重复执行。实际占领是所有势力的天下军事结果，不能冒充汉军战功。此采样没有直接下达地图军令，基线的零军议／零占领不表示旧版没有真实军事系统。

本轮结果体现三个可核验差异：不干预时，诸侯军议确实进入真实军事链；朝廷协调把16项真实军令转为朝廷协调责任，四项实际受害势力责任产生总计12点信任代价；劝止成功18次，使这一策略的天下占领由25次减为19次。拒令、少军粮、旧任务、目标改变等失败样本均保留，未换种子或调高兵力以获得成功。

协调与劝止占用了原本可用于筹款、召见等事务的行动，因此较低的总支出不表示更富裕，也不表示军事更优。协调不是即时获胜按钮，低调遣能力下交涉常被拒绝；劝止也不保证朝廷能控制外镇。全部到期仅说明这组可见状态策略能够完成剧本，不能当作玩家胜率或难度分布。

原有600条短局策略采样、240条顾问对照继续通过；短局／周挑战不生成新的自主军议。延康三路线及六种子专项亦保留其风险、实际支出与非普遍最优约束，详见[验证记录](VALIDATION_V226.md)。

机器可读完整结果为交付证据包中的`balance-final.json`，含60条轨迹及前后源码哈希。用`LORD_BASELINE_ROOT`指定572a47e归档后执行`node scripts/lord-command-balance.cjs`可重跑；`LORD_SCENARIO`可按剧本分组独立运行，汇总时须核对共同种子及源码哈希一致。
