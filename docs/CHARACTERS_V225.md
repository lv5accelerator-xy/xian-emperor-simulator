# v2.25 人物可用性与势力显示

`src/character-availability.js` 是当前人物、势力代表和显示身份的共同查询层。它读取当前核心的剧本、年份；缺失年份时由剧本起点与回合推算。普通局和短局采用相同人物规则，短局定向事件 ID 和顺序仍由短局模块控制。

## 身份和兼容

人物 ID 与势力 ID 分开：`cao_cao` 作为旧势力主键继续存在，但延康当前显示为“魏王府”，其代表为新人物 `cao_pi`。已有曹操关系、记忆、个人主议和过往记录仍属于曹操；曹丕关系从独立默认值 50 开始。新人物/机构的四维政治人格也从中性 50 建立，说明这是游戏参数，不宣称为史实评价。

## 其他剧本与有意保留的近似

不是逐月历史人物死亡系统。配置采用保守的年代边界，界限本身不是死亡日期：伏氏皇后身份自 195 年开放、215 年起关闭；董承和袁术自 200 年关闭；孙策自 201 年关闭；袁绍自 203 年关闭；刘表自 209 年关闭；荀彧自 213 年关闭；曹操自 220 年关闭。因此建安五年开局保留孙策到当年年末属于明确的开局角色池近似，不宣称他在真实 200 年全年活动。190 年前宫中事务由机构角色承接，不把伏氏提前称后。未在核心人物池配置的旧地方代表，在较早四个剧本保留原有开局势力近似；220 年统一改用地区机构。

回归检查五个普通剧本及 220 定向短局：召见、任官、密联和外镇列表均非空，六类季度议题各有三名有效主议。既有行动资格保留：任官仅排除当前掌权者；密联保留原可密联人物并明确配置可承办的使署，不把曹丕当作密联对象。当前不可用的旧主议保留历史，停止修正并开放重新选议；不退旧支出、不把剩余额度移交继任者。

## 共同入口与真正拒绝

- `availableCharacters(core,{action})`：当前合法列表，供核心面板、行动计划、推荐、比较、差遣和拟旨助手共用。
- `getCharacter(id,core)`：资料/历史查找，不等于可以行动；`isAvailable` 才决定当前资格。
- `representative(ownerKey,core)`、`faction(ownerKey,core)`、`commander(id,ownerKey,core)`：保留兼容主键，解析当前代表、势力与军司显示。军团调遣读取当前代表关系，避免沿用已故人物个人好感。
- `diplomaticTargets(text,core)`：识别当前称谓并按诏文首次出现位置返回原势力键，保留第一受命方与线路语义。州郡落实、军略和军团用同一识别；过世人物旧称不再构成当前命令。
- `validateTargets(text,core)`：预览和执行均拒绝当前不可受命的具名对象。伪造旧按钮/选择器不能消耗 AP、费用或 RNG。
- `initialRelations(core,existing)`：保留已有个人键，只为当前新角色补默认关系。完整导入和旧档继续同样执行。

人物篇章不会再生成不可用人物来信；旧档待决旧人物篇章停止，已经完成的章节和收藏不抹去。人物记忆页可保留真实旧记录，但问策按钮和处理器拒绝当前不可用者。新角色只从后续真实交往获得自己的记忆。

## 当前事件与旧记录

`presentEvent` 只复制正在呈现/执行的事件，不改全局事件数据和过往实录。当前模板里不可用的具名人物改由明确机构承办，原来针对旧人物的新事件关系变化记入相应当前角色的独立关系；事件文字明确提示“当前使署改编：机构关系另计，不承接旧人物经历”。例如当前“无名密书”的查验人改为尚书台使署，旧董承好感不受本次选择影响；曹操相关模板用魏王府的机构称谓，不全局替换为曹丕。江东求封模板在延康使用通使与奉表叙述，避免重演孙策讨袁术。原事件 ID 保留，定向短局调度不变；规则身份升级后重新验证新结果。

过去实录、人物记忆、战报和旧存档保留当时原文。新天下动态和诏令落实记录保存产生时的当前称谓，避免日后显示变化改写新事实归属。

## 已运行验证

修改前 `node tests/character-availability-regression.js` 失败于“220 opening says Cao Cao died: current actions must not target him”，证明当前版本仍把曹操放入可行动对象。修改后该文件通过 14 组功能回归，组数不是断言数：新局列表、伪造处理器对象、具名圣旨拒绝、曹丕独立关系、旧核心/完整导入、六类主议、其他四剧本、220 短局、当前事件复制、势力/军司身份、推荐器/比较、旧待决篇章和真实圣旨至天下落实。包含诏文对象顺序颠倒的专门断言。另新增五个剧本逐张点击真实人物卡片、打开详情并确认只读的回归；先复现机构角色缺少 publicTraits 导致详情报错，再为查询输出补齐明确的机构简介与公开特征。

另外运行 `council-advice-regression`、`progression-regression`、`progression-action-consistency-regression`、`legacy-systems-regression`、`grand-map-regression`、`campaign-evolution-regression`、`contract-parsing-regression`、`decree-resume-regression`，均退出 0。真实页面、移动布局及全量检查结果以本轮统一验证文档为准，本页的测试 DOM 适配器不充当浏览器验收。
