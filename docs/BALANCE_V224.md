## 策略与统计口径

| 策略 | 实际执行规则 |
|---|---|
| 守成 | 裁决本月奏报，不使用常用行动，直接月末。 |
| 重复召见 | 每月最多两次公开召见荀彧；不足行动或不能执行即停止。 |
| 民生 | 每次行动前国库低于 10 时核减冗费，否则局部赈济；最多两次。 |
| 密谋 | 泄密风险 ≥50、安全 ≤28 或警戒 ≥75 时公开召见荀彧，否则对董承建立情报线；最多两次。 |
| 按目标补缺 | 调用当时版本的 `XianCommandCenter.recommendAction`；建议守成就停止行动。 |

奏报选择按当前状态对选项的显式 effects/hidden 加权求和，分数并列取原列表首项。基础权重为皇权 0.4、安全 1.4、国库 0.6、百官 1、警戒 −1、泄密 −1，其他项目 0。民生策略改用民稳 1.6、威望 1、百官 0.7；密谋策略加忠汉网络 1.6、退路 0.6。补缺策略对每个短局目标覆盖权重：下限目标当前值低于下限+5时为4，否则1；上限目标当前值高于上限−8时为−4，否则−0.6。此算法不读取未来随机数。

- 金章率 = gold 行数 / 样本数。目标完成率 = 已达成目标数之和 / 全部目标数之和；每局均为三目标，所以每格分母为 72。
- 平均支出 = 已成功常用行动的 plan.cost 总和 / 样本数。**此矩阵未计奏报负国库、月末用度、强制损失；它不是全局财政流出。**
- 重复频率 = 当月同一 actionId + targetId（无对象为 none）的第二次及以后成功行动次数 / 成功行动总数。切换方式共用此键。零行动策略记为0.0%。
- 终值为各格的算术平均值，含上下限造成的真实截断，保留两位小数。提前结束读取结果的 endedEarly。
- 相同种子下按同一策略函数运行；策略因状态不同可能选择不同操作。因此这是配对策略对照，不能冒充逐步操作完全相同的时序一致性试验。

补缺策略在每个短局都保留 24/24 金章，合计 120/120。固定密谋策略的白马解围从 24/24 降至 23/24，是唯一金章数量变化的单元格；整体金章率从63.7%变为63.5%。重复召见策略的金章数量不变，但其终局收益下降，费用与行动点照旧。守成在白马解围、衣冠东归、许都夜变仍各有24/24金章，仍然具有策略价值。

据此保留本轮初始递减参数：首次完整收益，同月同类同对象后续行动的有利变化乘0.5并向零取整；费用和不利影响不减。它没有使五组短局失去可达金章路径。本轮没有比较0.25/0.75等其他系数，不能称0.5为最优参数。每季两次主议修正由行为回归确认生效与上限；本矩阵不主动选季度或采纳主议，因此不能用这600局量化主议的净收益或证明“两次”最优。
