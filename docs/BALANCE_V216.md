# v2.16 策略对照

每个短局以同一组 24 个配对种子分别运行守成、民生、密谋，共 360 局；另跑 120 局按目标补缺的可达性控制。使用实际事件按钮、常用行动确认、全部月份结算与终局评分，不直接修改国势、不跳月。

这是固定脚本的样本结果，不是真人胜率，也不说明三种路线在所有短局应当同样容易。

## 固定策略

- 守成：优先安全、官心和低警戒，不施行额外行动，保留两次行动的守成收益。
- 民生：优先威望、民间稳定和百官，每月一次局部赈济；国库低于 10 时改为核减冗费。
- 密谋：优先忠汉网络与退路，每月一次董承情报线；泄密风险≥50、宫廷安全≤28 或曹氏警戒≥75 时改为公开召见荀彧。
- 补缺控制：按实际短局目标选择事件并补足钱粮、皇权、官心或网络；曹氏警戒过高时先安抚。每月最多一次常用行动。

## 可达性与调整依据

| 短局 | 按目标补缺的金章 | 完整结算 |
|---|---:|---:|
| 白马解围 | 24/24 | 24/24 |
| 衣带诏影 | 24/24 | 24/24 |
| 衣冠东归 | 24/24 | 24/24 |
| 许都夜变 | 24/24 | 24/24 |
| 禅代前夜 | 23/24 | 24/24 |

- 白马解围中，固定赈济的国库均值只有 15，低于 25 的目标；因此主界面提示保留钱粮和月末用度。
- 衣带诏影中，守成和民生均止于忠汉网络 25，主动密联的策略能达标；因此目标差额需要一直可见。
- 密谋能建立网络，但在东归短局丢失官心，在部分白马、许都样本触及警戒目标；继续保留这种代价，避免把三类策略做成同一条路线。
- 禅代前夜需要主动恢复皇权。补缺控制能完成挑战，固定三类路线均无法补足皇权；提示玩家适量朝仪或任官，并监控警戒。
- 检查中发现旧圣旨会在资金不足时缩减支出，却仍保留政策收益。v2.16 改为预览与正式用玺统一检查完整预算，不足时保留草稿、显示原因且不扣行动。常用赈济原本已有预算拦截，现在两种入口一致。
- 短局终局目标不因某一种固定策略失败而降低；新增主流程目标、剩余月份和补缺建议，帮助玩家根据本局调整。

## 复现

```bash
node tests/balance-regression.js
node tests/balance-regression.js --json
node tests/decree-resume-regression.js
```

默认每组 24 个样本，种子为 `(index + 1) * 2654435761 >>> 0`，使用核心 mulberry32-v1 与子系统种子命名空间。所有玩法随机来自同一初始状态与种子；预览不消费随机序列。

完整汇总存于 `tests/fixtures/balance-v216.json`。脚本同时断言终局一定发生、最终目标值等于实际国势、民生保留财政代价与稳定收益、密谋保留适配目标和取舍，以及每个短局存在真实可达的金章路径。
