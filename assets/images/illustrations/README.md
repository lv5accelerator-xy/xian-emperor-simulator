# v2.7.0—v2.8.0 原创插图

本目录保存《天子蒙尘：献帝模拟器》使用的本地 WebP 场景图。图片均为本项目通过 OpenAI 内置图片生成模式制作的原创素材，没有外部图床依赖，也没有在画面中生成文字、标志或水印。

| 文件 | 游戏用途 | 画面主题 |
| --- | --- | --- |
| `opening-palace.webp` | 开始界面 | 暮色宫阙中的少年天子 |
| `court-memorial.webp` | 朝政类奏报 | 御前朝议与呈递奏疏 |
| `army-crossing.webp` | 军事类奏报、军团窗口 | 军团辎重渡河与山口烽燧 |
| `ending-river-mountains.webp` | 终局界面 | 空台、冠服、印玺与山河晨光 |
| `treasury-crisis.webp` | 国库奏报 | 空库、账簿与焦灼度支官 |
| `granary-relief.webp` | 赈济奏报 | 官仓开廪与百姓领粮 |
| `secret-edict.webp` | 密诏奏报 | 深夜宫灯与封缄诏书 |
| `regional-envoys.webp` | 外镇奏报 | 州郡使者入朝献表 |
| `palace-guard.webp` | 宫禁奏报 | 宫门换防与宿卫列阵 |
| `military-dispatch.webp` | 军情奏报 | 急使驰入军帐呈报 |

统一美术方向：东汉末年历史氛围、写意工笔与水墨融合、暗金和朱红点色、克制的电影光影。构图为宽幅 16:9，并为界面文字与移动端裁切预留负空间。v2.8.0 的六幅新场景以原有朝议、行军插图作为风格参考，分别针对财政、民政、权谋、外交、宫禁和军情主题生成。

运行时只加载 WebP 成品。源生成图保留在开发环境的图片生成目录中，不随游戏发布包分发。
